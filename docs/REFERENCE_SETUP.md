# 实体色卡设置：不用编写 JSON

**先确认实际色卡，后导入它的参考文件。** 本项目没有替你选购型号，没有真实色卡通用数值，也没有自动从网络下载数据。数值流程需要你已经拥有或明确选择的哑光多色块参考卡，以及对应型号、版本或实测批次的可信参考。型号还未知时，可以使用照片日志；真实照片的数值比较仍等待色卡和来源确认。

## 1. 向制造商取得正确文件

找到实物包装上的制造商、完整型号、版本/生产批次。向制造商支持索取：

> 这张具体型号和批次的色块参考数据，CSV 或 CGATS 文本，含每块 ID / 标签、CIE Lab（D50 / 2°）或 XYZ（D50 / 2°，注明 Y=1 还是 Y=100）、标签排列图和数据版本。

参考来源可以是厂商的正式文件，也可以是有明确测量设备、条件和来源的该张色卡实测数据。不要拿相似型号、未知版本、网页颜色或打印的演示色块代替。只给光谱、RGB、D65 或 10° 的文件不在当前支持范围；向来源方要求所需 D50 / 2° 数据，不要自己改标签。

X-Rite 的官方支持索引列有 [ColorChecker 新旧色彩规格](https://www-prod10.xrite.com/service-support/new_color_specifications_for_colorchecker_sg_and_classic_charts)，并区分 2014 年前后参考数据；另有 [Digital SG 色度值说明](https://www.xrite.com/pt-pt/service-support/colorimetric_values_for_colorchecker_digital_sg)，搜索索引说明其数据为 D50 / 2° Lab。这些是联系/核对来源的入口，不是推荐购买或保证适配：本次直接访问分别返回 502/403，未下载、重分发或验证任何商业数据文件。请向你的实际制造商核对；本软件不证明厂商文件的真实性或授权。遵守原文件的使用许可。

## 2. 支持什么文件

- CSV：第一行列名，逗号、分号或制表符分隔；每行一个色块。向导让你选择哪四列分别是色块 ID 和三个分量，不必重命名原列
- CGATS 文本：一个 `BEGIN_DATA_FORMAT` / `END_DATA_FORMAT` 列名段，一个 `BEGIN_DATA` / `END_DATA` 数据段；常见字段 `SAMPLE_ID LAB_L LAB_A LAB_B` 或 `SAMPLE_ID XYZ_X XYZ_Y XYZ_Z`
- 6–256 个唯一色块 ID；UTF-8 文本，最多 1 MB。多个测量集合请让厂商导出需要的单一数据表。Excel 文件先用 Excel/LibreOffice 另存 UTF-8 CSV，原文件保留
- XYZ 0–100：向导除以 100；XYZ 0–1：保留原比例；Lab D50：向导按 CIE Lab 逆公式和固定 D50 白点转换到 XYZ。它不做照明体转换，不把 D65 冒充 D50
- 受支持条件字段已声明其他 illuminant/observer 时拒绝导入（精确支持范围见下文）。文件未声明时，需要你在向导明确核对来源文档，不会自动猜测

## 3. 点选式操作

1. 在应用点击「设置实体色卡」，选择刚取得的 CSV / CGATS / TXT
2. 填制造商、实物型号、版本/批次、来源网页/文档编号，和色块布局说明。例如“按照包装背面 A1…D6 标签图”；不要猜测先横后竖
3. 按来源文档明确选择 D50、2°、Lab / XYZ 与单位；在四个列选择框中匹配 ID 和数据分量。Lab 使用 L*, a*, b*，XYZ 使用 X,Y,Z
4. 核对确认项，点「验证并预览」。检查色块个数、ID 和顺序。程序检查退化、非有限和不合理数据，但这些检查不能证明数据属于你的色卡
5. 点「保存本地配置并使用」，选择新的 JSON 文件名。应用替你生成配置；无需编辑 JSON。保存包括文件 SHA-256、原列选择、原始元数据、来源、版本、色块标签和转换后的 XYZ
6. 拍摄时把实物与皮肤放在同平面同光照。在「色块顺序」查看标签清单，按清单逐块框选内部，避开边界。图上蓝框同时显示序号与厂商标签；并非程序自动猜测实物布局
7. 实际照片仍需通过拟合与人工质控。换配置会清除旧参考框和“实物对应”确认，必须重新对应。邻近皮肤不能用于把真实痣变化“校正掉”

## 实际使用仍需完成的确认

向导解决文件准备与单位转换，不替代实际色卡选型、来源核验或真实设备重复性测试。没有已确认的卡片与正确参考文件时，不能称真实照片标定已完成。物理卡片磨损、批次差异、HDR、局部阴影和光谱差异都可能使数值不可靠。只保存照片或重新拍摄都比伪造可比较数据更合适。

## 明确支持的 CGATS 条件声明

导入器不是通用 CGATS / CTI3 校准工具。它只支持单一色块表、相对反射参考数据，以及下列有明确一致性检查的声明；不做任何色适应转换：

- `ILLUMINANT` / `ILLUMINATION_NAME` 必须为 D50；`OBSERVER` / `OBSERVER_ANGLE` 必须表示 2°
- `ILLUMINANT_WHITE_POINT_XYZ` 必须是三个有限正数。先除以声明的 Y，再与固定 D50 `[0.96422, 1, 0.82521]` 比较，绝对容差 0.0005 用于舍入误差。数值 D65 不会因下拉框选了 D50 而被重新贴标签
- `COLOR_REP` 的 CIE 分量必须与 Lab / XYZ 选择一致；标准 `LAB_L/A/B`、`XYZ_X/Y/Z` 或 L/a/b、X/Y/Z 列名也会检查类型与分量顺序。一般自定义 CSV 列仍由你明确映射并核对单位
- `NORMALIZED_TO_Y_100 YES` 要求 XYZ 0–100；其他归一化声明当前拒绝。识别到 CTI3 标识时，XYZ 按该格式的 Y=100 规则检查。显示器/其他设备类和绝对亮度数据不作为物理参考卡导入
- 重复条件字段使用不同值时拒绝，不能靠最后一行覆盖前一行。重复的 `KEYWORD` 只是字段声明，不作为条件值处理
- 未支持但涉及光源、白点、观察者、单位、比例等的命名字段会拒绝，要求提供受支持的明确导出。不会从任意自由文本或所有可能的厂商字段中推断条件；来源文档核对仍然必需

这些条件也会在生成的配置重新载入/用于测量时重新检查，不能通过保存 JSON 绕过已知冲突。[Argyll 官方 TI3 格式说明](https://www.argyllcms.com/doc/ti3_format.html)定义了数值光源白点和归一化字段；软件只实现上述狭窄子集，不声称覆盖整个规范。
